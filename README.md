# ActOut
"ActOut" or "ActuatorOutput" is a unified MATLAB, Simulink Model-Based-System-Engineering architecture providing rapid iteration, visualization, and dynamic simulation of mechatronic and robotic actuator systems. Built by FAMU-FSU Capstone Team 518 for NASA's Jet Propulsion Laboratory.
